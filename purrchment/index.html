What it is

Purrchment keeps your own HTML pages – we call them parchments – and opens them on your phone, offline.

Did you make a small tool, game or calculator with an AI assistant, or write one yourself? Paste the HTML or open a .html file, and Purrchment saves it in your library. Tap it to use it at any time, also without internet.

What you can do

  • Add a parchment: paste HTML from the clipboard, open a .html file, or type it.
  • Organize: search, categories and your own icons.
  • Keep data: each parchment can save its own data on your phone, for example a list or a score. The data stays after a restart.
  • Back up: export everything to one file and import it on another phone.
  • Start fast: three demo parchments, and a ready-made prompt that asks an AI assistant for a phone-friendly page.

How to add a parchment

Paste from the clipboard

Copy the HTML code, for example from an AI chat. In Purrchment, tap the Paste button (clipboard icon) at the top.

Load a .html file

Save the HTML as a file that ends in .html. In Purrchment, tap the Open file button (folder icon) and select the file.

Make one with an AI assistant

In Purrchment, open the menu (⋮) and tap How to add parchments. Copy the AI prompt, give it to your AI assistant with your idea, then paste the HTML it writes.

Only add HTML that you trust. A parchment is a program. HTML can be written to do harm: a page can look like a bank or login screen and ask for your password, show fake warnings, or ask for your camera, microphone or location without a good reason. The sandbox blocks network and file access, but no sandbox can stop a page from tricking you.

Never type passwords, card numbers or other secrets into a parchment. If you are not sure about a page, do not add it.

Privacy

  • No data collection, no analytics, no tracking. The developer cannot see your parchments or their data.
  • Works offline. Purrchment downloads nothing until you allow it. If a parchment links to online script, style or image files, Purrchment asks first and names each server. It downloads only those files and keeps them on your phone. Each parchment's details show these servers, and you can remove them there at any time.
  • Android cloud backup is off. Your data leaves the phone only when you export a backup file yourself. Backup files are not encrypted.

Read the full privacy policy.

Safety

Each parchment runs in its own sandbox. Purrchment blocks it from the internet, and it cannot read your files, other apps or other parchments. A parchment can use the camera, microphone or location only after you allow it for that parchment. Each parchment's details show what it may use, and you can remove it there at any time.

What Purrchment is not

Purrchment is not a web browser and not an app store. It does not download or install apps. It shows only the HTML pages that you add yourself.
