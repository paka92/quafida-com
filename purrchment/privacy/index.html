Purrchment privacy policy

Effective date: 2 October 2026

This policy applies to the Android app Purrchment (package com.quafida.purrchment).

Summary

Purrchment does not collect, send, sell or share any personal data. It has no account, no ads, no analytics and no tracking.

What the app stores, and where

Purrchment stores the following only on your device, in the app's private storage:

  • the HTML pages that you add (called parchments), their names, descriptions, categories and icons;
  • the data that each parchment saves for itself (web storage);
  • copies of online files that your parchments link to, if you allow the download;
  • the servers that you allowed downloads from, per parchment;
  • your app settings.

The developer cannot see this data. Android cloud backup and device-to-device transfer are turned off for this app. Uninstalling the app deletes all of this data.

Backup files

When you use "Export backup", the app writes all parchments and their saved data to a file at a place that you choose. The file is not encrypted: anyone who has the file can read its content. The app never sends this file anywhere. What happens to the file after that (for example if you put it in a cloud folder) is under your control.

Network

Purrchment downloads nothing until you allow it for a parchment.

If a parchment links to online script, style or image files, Purrchment asks you first and names each server. If you allow it, Purrchment downloads, over HTTPS, only those files, and keeps them on your device. Your choice is saved for that parchment and those servers only, until you remove it in the parchment's details, which also deletes the files. For a new server, Purrchment asks again.

These requests go directly to the server that hosts each file (for example a content delivery network). That server receives your IP address and the address of the file, as with any download, and its own privacy policy applies. Purrchment sends no other data with these requests.

While a parchment runs, Purrchment blocks it from the internet. The app answers every request of the parchment itself, with the page or with the files saved for offline use. The page's security policy blocks connections to other servers, and the browser feature that opens direct connections (WebRTC) is turned off.

Camera, microphone and location

A parchment can ask for the camera, the microphone or your location. Purrchment then asks you first. Only if you allow it does Android ask for its permission. The data goes only to that parchment, on your device. Your choice is saved for that parchment only, until you remove it in the parchment's details; other parchments must ask for themselves. When no parchment uses a feature any more, Purrchment gives the Android permission back (Android 13 and later). Purrchment does not record, store or send this data.

Files

A parchment can ask you to pick a file. The system file picker opens, and the parchment gets only the file that you pick.

Data from Google Play

Google Play and Android can give the developer statistics about crashes and performance (Android vitals) from users who have agreed to share usage and diagnostics data with Google. Google collects this data under the Google Privacy Policy; the app itself does not collect it.

Children

Purrchment is not directed at children under 13.
