# quafida.com

Static website of Quafida apps, served by GitHub Pages at https://quafida.com.

- `/` – list of apps
- `/purrchment/` – Purrchment app page
- `/purrchment/privacy/` – Purrchment privacy policy (Play Console privacy policy URL)

No build step, no JavaScript, no cookies, no external resources.

The privacy policy text comes from `docs/privacy-policy.md` in the app repository. Change both
together. Each new app gets a folder (`/<app>/` and `/<app>/privacy/`) and a card on `index.html`.
